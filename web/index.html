連接你的模型

金鑰安全：API Key 會由你的瀏覽器直接傳給你選的 API 服務商，這個網站不會經手或代存。首次建議不要勾選記住金鑰。

輸入相容服務的 base URL，不需加上 /chat/completions。僅支援 HTTPS。

「任何 API」指支援 OpenAI Chat Completions 格式且允許瀏覽器跨來源連線的服務。各服務的模型名稱、額度和內容政策由服務商決定。
